# Support

Questions: [GitHub Discussions](https://github.com/getagentseal/codeburn/discussions).

Chat: [Discord](https://discord.gg/w2sw8mCqep).

Bugs: open an issue using the bug report form.

Security vulnerabilities: use the private reporting link in [SECURITY.md](SECURITY.md), not a public issue.
Don't file an issue for a question, a "how do I", or a feature idea you haven't checked Discussions for first — use Discussions or Discord instead.
